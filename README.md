# Funniest Forecast for a City That Isn't

A weather forecast for Dribbleton, a city that does not exist, in 100 characters, for make.fun's "Funniest Forecast for a City That Isn't" bounty. `main.py` writes the forecast to `/output/entry.txt`.

> In Dribbleton, rain falls upwards today. Umbrellas will not help. Hats are advised, worn underneath.

In Dribbleton the rain falls up, so the umbrella — the one tool a forecast ever recommends — is useless, and the official advice has to be worn underneath instead.
